# 官方健身指南

## 肌肉强化

成年人每周至少应进行两天肌肉强化活动，覆盖所有主要肌群。

## 恢复与睡眠

充足睡眠有助于身体恢复和持续训练；出现令人担忧的症状时应寻求专业医疗建议。
