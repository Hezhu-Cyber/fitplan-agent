## 目的:澄清

在PA水平提高和妊娠糖尿病风险降低之间是否存在剂量-反应关系。 摘要:在流行病学研究中,体育活动一直与孕期糖尿病症的风险有不一致的联系,对两者剂量反应关系的强度和形状仍有疑问. 因此,我们系统地审查并进行了关于体育活动和妊娠糖尿病的组群研究和随机试验。 PubMed、Embase和Ovid数据库被搜索到组群研究,以及截至2015年8月5日对体育活动和妊娠糖尿病风险的随机控制试验。 使用随机效应模型估计了相对风险摘要。 包括25份研究报告(26份出版物)。 在总的体育活动中,高活度与低活度的粗略恢复训练在怀孕前分别为0.62(95%CI 0.41-0.94,I2 = 0%,n = 4)和0.66(95%CI 0.36-1.21,I2 = 0%,n = 3)。 在业余体育活动中,高活度与低活度的相对比分别为怀孕前的0.78(95%CI 0.61-1.00,I2 = 47%,n = 8),怀孕期间为0.80(95%CI 0.64-1.00,I2 = 17%,n = 17)。 怀孕前活动总死亡率为每周5小时0.70(95%CI 0.49-1.01,I2 = 72.6%,n = 3),怀孕期间活动总死亡率为每周5小时0.98(95%CI 0.87-1.09,I2 = 0%,n = 3)。 有证据表明,怀孕前的体育活动与妊娠期糖尿病的风险之间有非线性联系,非线性=0.005,活动水平较低时的关联程度略高,尽管观察到风险进一步降低,达到每周10小时。 还有证据表明早孕时的体育活动无线性,非线性=0.008,但风险不会进一步降低到每周8小时以上。

有一些迹象表明,行走(怀孕前和怀孕期间)和活跃活动(怀孕前)与妊娠糖尿病的风险之间存在反向联系。 这一荟萃分析表明,怀孕前和早孕期间的体育活动与孕期糖尿病的风险之间存在着明显的反向联系。 需要进一步研究,以澄清活动的具体类型和强度与妊娠糖尿病之间的联系。
