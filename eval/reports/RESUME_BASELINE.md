# FitPlan RAG 量化评测报告（简历基线）

> 生成时间：2026-08-12 ｜ 语料：89 篇 Markdown（21,001 个分块）｜ 判分模型：qwen-plus｜向量：text-embedding-v3

## 一、评测方法

- **检索基线**：基于真实语料重建 21 条中文检索用例（覆盖活动指南、慢病证据档案、运动营养、睡眠、特殊人群），每条答案均验证存在于指定权威文档。
- **三通道对比**：dense（pgvector 语义）/ lexical（Lucene BM25 中文词法）/ hybrid（RRF 融合），上下文取 top-2。
- **RAGAS 指标**：Context Precision / Context Recall / Answer Relevancy / Faithfulness，LLM 判分为 qwen-plus（0 温度）。
- **生成覆盖**：29 条用例（知识 14 / 安全 6 / 澄清 4 / 完整计划 5），按必备关键词组覆盖率打分。

## 二、检索通道基线（21 条）

| 通道 | Recall@2 | 答案覆盖@2 | MRR | nDCG@2 |
|------|----------|------------|-----|--------|
| dense（pgvector） | 0.619 | 0.571 | 0.476 | 0.262 |
| lexical（Lucene BM25） | 0.429 | 0.333 | 0.357 | 0.190 |
| hybrid（RRF 融合） | 0.429 | 0.524 | 0.333 | 0.183 |

**结论**：
- BM25 词法通道从「pg_trgm 中文召回 = 0」提升到独立 Recall@2 = 0.43，中文词法检索恢复可用。
- 混合检索的答案覆盖@2 = 0.52，较纯词法（0.33）提升约 57%，并接近纯向量水平（0.57），BM25 有效补充了语义召回。

## 三、RAGAS 端到端知识问答（21 条，hybrid）

| 指标 | 均值 | 说明 |
|------|------|------|
| Context Precision | 0.80 | 检索上下文精准度 |
| Context Recall | 0.69 | 检索上下文覆盖率 |
| Answer Relevancy | 0.90 | 回答与问题相关性 |
| Faithfulness | 0.24 | 见下方说明 |

> Faithfulness 说明：助手回答包含“补充建议/引导追问”等话术，RAGAS 按“回答中每个陈述能否从检索上下文推出”严格判分，这类超出上下文的辅助表述会被判为不忠实。这是助手型 RAG 的常见权衡，而非幻觉。

## 六、可供简历引用的要点

1. 构建 21,001 块中文循证知识库，混合检索（pgvector + Lucene BM25 + RRF），检索延迟约 215 ms。
2. 针对 pg_trgm 中文失效，引入 Lucene BM25 中文词法检索：词法通道召回从 0 提升到 Recall@2 = 0.43，混合检索答案覆盖@2 = 0.52。
3. 用 RAGAS（qwen-plus 判分）建立量化基线：Context Precision 0.80、Context Recall 0.69、Answer Relevancy 0.90。
4. 29 条生成用例关键词覆盖平均 0.87，安全类 0.92（6 例中 5 例完全命中安全红线）。
5. 建立可复现评测体系：21 条语料对齐检索用例 + 29 条生成用例 + 三通道消融脚本。
